# File Management Guide

This document describes how to manage files in this repository to avoid Git history bloat while keeping all necessary data files.

## Repository Structure

```
drawdown_dashboard/
├── src/                    # Source code (always tracked)
├── pages/                  # Streamlit pages (always tracked)
├── input/                  # Input data files
│   ├── ark_etfs/          # ARK ETF data
│   │   ├── *.parquet      # Transformed data (TRACKED)
│   │   ├── *.csv          # Ticker lists (TRACKED)
│   │   ├── *.xlsx         # Source files (IGNORED - large)
│   │   └── precomputed/   # Precomputed analysis (TRACKED)
│   ├── russell_3000/      # R3000 data
│   │   ├── *.parquet      # Transformed data (TRACKED)
│   │   ├── *.csv          # Cache files (TRACKED)
│   │   ├── *.xlsx         # Source files (IGNORED - large)
│   │   └── precomputed/   # Precomputed analysis (TRACKED)
│   ├── industry_mappings/ # GICS mappings (TRACKED)
│   ├── companyname_mappings/ # Company names (TRACKED)
│   └── precomputed/       # Global precomputed data (TRACKED)
├── output/                 # Output files
│   └── *.csv              # ETF price files (TRACKED)
└── data/                   # Runtime cache (IGNORED)
```

## File Categories

### 1. TRACKED Files (Must be in Git)

These files are required for the app to run on Streamlit Cloud:

| File Type | Location | Description |
|-----------|----------|-------------|
| `*.parquet` | `input/ark_etfs/` | Transformed ARK ETF holdings data |
| `*.parquet` | `input/russell_3000/` | Transformed R3000 holdings data |
| `*.parquet` | `input/*/precomputed/` | Precomputed drawdowns, correlations, etc. |
| `*.csv` | `input/ark_etfs/` | Ticker lists |
| `*.csv` | `input/russell_3000/` | Ticker lists, drawdown cache |
| `*.csv` | `output/` | ETF price data (ARKK, ARKG, etc.) |
| `*.xlsx` | `input/industry_mappings/` | GICS industry mappings |
| `*.xlsx` | `input/companyname_mappings/` | Company name mappings |
| `*.json` | `input/precomputed/` | Metadata |

### 2. IGNORED Files (Not in Git)

These files are either too large or regenerable:

| File Type | Location | Reason |
|-----------|----------|--------|
| `*.xlsx` | `input/ark_etfs/` | Large source files (35MB+), use parquet instead |
| `*.xlsx` | `input/russell_3000/` | Large source files, use parquet instead |
| `*.jpg` | `input/spx/` | Image files, not needed for app |
| `__pycache__/` | everywhere | Python cache, regenerated automatically |
| `.DS_Store` | everywhere | macOS system files |
| `data/cache/` | `data/` | Runtime cache |
| `data/precomputed/` | `data/` | Old precomputed location (now in input/) |

## Workflow

### Adding New Data

1. **Source Excel files** (`*.xlsx`):
   - Keep locally for data updates
   - Do NOT commit to Git (too large)
   - Run `python convert_to_parquet.py` to convert to parquet

2. **Parquet files** (`*.parquet`):
   - Always commit these
   - Much smaller than xlsx
   - Required for app to run

3. **Price files** (`output/*.csv`):
   - Generated by `python src/fetch_prices.py`
   - Always commit these
   - Required for charts and analysis

### Updating Data

When you update source Excel files:

```bash
# 1. Convert xlsx to parquet and generate precomputed data
python convert_to_parquet.py

# 2. Update price data (if needed)
PYTHONPATH=. python src/fetch_prices.py
PYTHONPATH=. python src/fetch_iwv_prices.py

# 3. Commit all changes
git add input/ output/
git commit -m "Update data files"
git push
```

### Cleaning Git History (If Needed)

If Git history becomes too large due to data file changes:

```bash
# 1. Backup data files
cp -r input /tmp/backup_input
cp -r output /tmp/backup_output

# 2. Clean history (removes ALL history of specified paths)
git filter-repo --path input/ark_etfs/*.xlsx --path input/russell_3000/*.xlsx --invert-paths --force

# 3. Restore data files
cp -r /tmp/backup_input/* input/
cp -r /tmp/backup_output/* output/

# 4. Re-add remote and force push
git remote add origin https://github.com/YOUR_REPO.git
git add .
git commit -m "Re-add data files after history cleanup"
git push --force origin main
```

## Size Guidelines

| Category | Max Size | Action if Exceeded |
|----------|----------|-------------------|
| Single file | 50MB | Convert to parquet or split |
| Total repo | 500MB | Clean git history |
| `.git` folder | 100MB | Clean git history |

## Checking Repository Size

```bash
# Check .git size
du -sh .git

# Check total repo size
du -sh .

# List large files
find . -type f -size +5M -exec ls -lh {} \;

# List files in git by size
git rev-list --objects --all | git cat-file --batch-check='%(objecttype) %(objectname) %(objectsize) %(rest)' | awk '/^blob/ {print $3, $4}' | sort -rn | head -20
```
